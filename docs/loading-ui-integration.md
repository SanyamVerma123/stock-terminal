# Loading and UI Enhancement Notes

The uploaded project already contains a native `InlineLoading` animation in `src/components/ui/loading-state.tsx`. It uses the project’s primary-colored three-dot motion treatment and supports compact `pulse-dot` and `wave` variants. The enhancement will extend this source-native animation into quote tables, screeners, market news, calendars, options, search, stock history, and chart loading states.

The supplied 21st.dev archive provides compatible visual references for a larger loading spinner, skeleton surfaces, cards, shimmer buttons, and empty-state treatments. The project will reuse these patterns as source-compatible CSS and React enhancements without introducing a separate visual system or external animation runtime.
