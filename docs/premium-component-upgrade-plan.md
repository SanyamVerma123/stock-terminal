# Premium Component Upgrade Plan

| Surface | Current presentation | Upgrade treatment |
| --- | --- | --- |
| Market-weight heatmap | SVG mosaic with basic hover | Add a focused leader card, refined tile contrast, structured legend, and responsive spotlight interaction. |
| Stock comparison | Input and line chart | Add ticker chips, performance summary cards, period controls, and an elevated chart surface. |
| Stock header | Research information with no direct action | Add persistent watch/unwatch control backed by the existing local watchlist state. |
| Dashboard data | Reusable table-heavy presentation | Pair core data with compact metric cards, rank chips, visual bars, and chart-led summaries. |
| Economic calendar | Category chips plus data table | Add a premium calendar toolbar, event highlight cards, and category-specific visual cues. |
| Sector workspace | Mosaic and generic bar chart | Add visual sector performance bands, interactive focus state, and better empty/loading surfaces. |

All enhancements will reuse the existing data contracts and client-state persistence. The visual direction uses the supplied 21st.dev archive as a reference for elevated cards, segmented filters, compact metrics, and empty/loading states rather than introducing a second design system.
